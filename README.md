# PhipiShip

**PhipiShip** — бесплатный растровый графический редактор, который работает прямо в браузере.
Без установки, без сервера, без сборки: открыл `index.html` — и рисуешь. Картинки
обрабатываются локально и никуда не отправляются.

## Запуск

- Просто откройте `index.html` в браузере (Chrome, Edge, Firefox, Safari).
- Или включите **GitHub Pages** (Settings → Pages → ветка с файлами, папка `/`) — получите онлайн-версию по ссылке.

## Возможности

| Раздел | Что есть |
|---|---|
| Инструменты | Перемещение, Кадрирование, Кисть, Ластик, Заливка (с допуском), Пипетка, Текст, Линия, Прямоугольник, Эллипс, Рука, Масштаб |
| Слои | Создание, дублирование, удаление, порядок, видимость, переименование (двойной клик), непрозрачность, 16 режимов наложения, объединение, сведение |
| Изображение | Размер изображения, размер холста с привязкой, поворот на 90°, отражение |
| Фильтры | Яркость/Контраст, Тон/Насыщенность, Обесцветить, Инверсия, Сепия, Размытие, Резкость, Шум, Пикселизация, Порог — с живым предпросмотром |
| Файлы | Открыть, поместить как слой, перетаскивание файлов, вставка из буфера (Ctrl+V), сохранение PNG, экспорт JPG |
| Прочее | Отмена/повтор, палитра, масштаб колесом мыши, горячие клавиши (Справка → Горячие клавиши) |

## Структура

```
index.html   — разметка интерфейса
style.css    — оформление (собственная тёмная тема)
app.js       — вся логика редактора
logo.svg     — оригинальный логотип (кораблик)
```
